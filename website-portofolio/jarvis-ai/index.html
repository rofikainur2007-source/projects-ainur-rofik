🤖 Jarvis AI

Personal AI Assistant

Personal AI assistant berbasis Python yang dikembangkan untuk membantu interaksi suara, menjalankan aplikasi dan melakukan berbagai perintah melalui komputer.

Fitur Jarvis AI

🎤 Voice Command

Menerima perintah suara dan mengubahnya menjadi perintah yang dapat diproses komputer.

🧠 AI Assistant

Sistem assistant yang dapat memproses pertanyaan dan perintah pengguna.

💻 App Control

Membantu membuka aplikasi komputer menggunakan perintah suara.

⌨️ Text Automation

Mendukung otomatisasi pengetikan teks berdasarkan perintah pengguna.

🐍 Python Based

Dikembangkan menggunakan Python dan berbagai library pendukung AI serta automation.

⚙️ Hybrid Assistant

Dirancang agar dapat menggabungkan kemampuan lokal komputer dengan layanan AI.

🚧 Development

Jarvis AI masih terus dikembangkan dengan penambahan voice command, kontrol aplikasi, automation dan kemampuan assistant lainnya.
